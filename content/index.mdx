<Section
  title="Add “Sign in with Valyd” — the whole login"
  sub="A two-line button on the front end, one Valyd object on the back. That is the login."
  index={1}
>

```html
<!-- Front end — the whole button -->
<script src="https://idp.valyd.work/signin/client.js" async></script>
<div class="valyd-signin"
     data-client-id="YOUR_CLIENT_ID"
     data-redirect-uri="https://yourapp.com/callback"></div>
```

```typescript
// Back end — one Valyd object from your keys
import { Valyd } from "@valyd/sdk";
const valyd = new Valyd({
  clientId: process.env.VALYD_CLIENT_ID,
  clientSecret: process.env.VALYD_CLIENT_SECRET,
});

const { user } = await valyd.auth.handleCallback(req.url, {
  expectedState: req.cookies.valyd_oidc_state,  // the button set this cookie
});
// user.valyd_id · user.id_verified — signed in
```

</Section>

<ZigRow
  index={1}
  side="left"
  kicker="Recommended"
  title="Host a flow of checks — tied to the user's identity"
  cta={{ href: '/verifications/managed', label: 'How it works' }}
  body={<>Pick the checks in the portal — KYC, liveness, license, age — that's your workflow.
  Send the signed-in user to one hosted page; they complete everything there. You get back{' '}
  <b>non-PII results and proofs</b> — the personal data stays with us, encrypted, and the proof
  saves to their Valyd ID. Next time you just <a href="/docs/endpoints">read it</a>.</>}
>

```typescript
// One call — the user's token ties the flow to their identity:
const session = await verify.sessions.create({
  workflowId,                      // the checks you picked in the portal
  valydAccessToken: accessToken,   // ← ties it to the user
  redirectUrl: "https://yourapp.com/verified",
});
// → send them to session.url — proofs come back, PII doesn't
```

</ZigRow>

<ZigRow
  index={2}

  body={<>The exact same hosted flow, no login, no token: we run the checks and hand the{' '}
  <b>full results — identity data included — to your system</b>. We keep no identity data —
  only the check-outcome record for billing and audit (<a href="/verifications/data-sharing">details</a>).
  You don't even need a login app: one dialog creates a{' '}
  <a href="/verifications/setup">verification-only project</a> with its own key and workflows.</>}
>

```typescript
// Same call — no token, so the data comes home to you:
const session = await verify.sessions.create({
  workflowId,                      // the same checks
  redirectUrl: "https://yourapp.com/done",
});
// → send them to session.url — full results return to you
//   (we keep no identity data)
```
