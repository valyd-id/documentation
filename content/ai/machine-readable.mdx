# Machine-readable docs

Point any agent at these resources to **read and learn** Valyd by plain fetch — the lightweight
alternative to a docs MCP server, with nothing to run. Everything here is same-origin and served as
static files.

## The resources in one table

| Resource | URL | What it is |
| --- | --- | --- |
| Docs index | [`/llms.txt`](/llms.txt) | Link-first index of every page. |
| Full corpus | [`/llms-full.txt`](/llms-full.txt) | Every page concatenated into one file. |
| Verification OpenAPI | [`/openapi/valyd-verify.json`](/openapi/valyd-verify.json) | OpenAPI 3.1 for the Verification API. |
| Login OpenAPI | [`/openapi/valyd-id.json`](/openapi/valyd-id.json) | OpenAPI 3.1 for Login with Valyd. |
| Capability manifest | [`/agent/capabilities.json`](/agent/capabilities.json) | Discoverable capability summary. |
| Agent guide | [`/ai/agent-guide`](/ai/agent-guide) | How to integrate as an agent. |

Per-page `.md` mirrors are linked from `llms.txt` — every doc page is also fetchable as plain
Markdown at its own `.md` URL. Prefer callable tools over reading? See the
[MCP server quickstart](/ai/mcp-setup).
