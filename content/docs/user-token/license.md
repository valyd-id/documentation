# License verification

> 📄 **This page moved.** Credential (license) verification is documented in one canonical place:
> **[Credential verification](/verifications/standalone/credential-verification)**. This stub stays
> so old links keep working.

Verifying a license for a signed-in user is a **[Managed by Valyd](/verifications/managed)** check —
you run it on a hosted session with the user's `valyd_access_token`, so it matches against the
account's verified name and the passed badge saves to their Valyd ID. (Professional-license
verification is not a self-serve direct call.) See
[Credential verification](/verifications/standalone/credential-verification).
