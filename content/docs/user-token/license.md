# License verification

> 📄 **This page moved.** Credential (license) verification is documented in one canonical place:
> **[Credential verification](/verifications/standalone/credential-verification)**. This stub stays
> so old links keep working.

Verifying a license for a signed-in user is the **same call** as the one-off check — you just add
the user's `valyd_access_token`, so it matches against the account's verified name and the passed
badge saves to their Valyd ID. See
[Credential verification](/verifications/standalone/credential-verification).
