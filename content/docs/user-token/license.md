# License verification

> 📄 **This page moved.** Credential (license) verification is documented in the
> **[checks reference](/verifications/types)**. This stub stays so old links keep working.

Professional-license verification is a **workflow check** inside
[Reusable Verification](/verifications): run a configured [workflow](/verifications/workflows)
on a session with the user's `valyd_access_token`, and the license matches against the account's
verified name with the passed badge saving to their Valyd ID. (It is not a public API call.) See
the [checks reference](/verifications/types).
