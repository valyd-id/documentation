# Liveness

> 📄 **This page moved.** Liveness is documented in one canonical place:
> **[Liveness](/verifications/standalone/antispoof)** — part of the
> [Unique Human API](/verifications/standalone). This stub stays so old links keep working.

The Unique Human API answers "is this a live person?" with an API key alone — a no-account
workflow session on Valyd's verification page, verdict returned to you. For a connected user, liveness is
also available as a **workflow check** inside [Reusable Verification](/verifications), so the
assurance rides on their account. See [Liveness](/verifications/standalone/antispoof) and the
[checks reference](/verifications/types).
