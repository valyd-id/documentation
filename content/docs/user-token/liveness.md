# Liveness

> 📄 **This page moved.** Liveness is documented in one canonical place:
> **[Liveness](/verifications/standalone/liveness)**. This stub stays so old links keep working.

Liveness runs in **either lane**. For a signed-in user, run it on a
**[Managed by Valyd](/verifications/managed)** session with the user's `valyd_access_token`, so the
assurance rides on their account. Tokenless, with nothing saved, it's a
**[Verify Fresh](/verifications/standalone)** check. See
[Liveness](/verifications/standalone/liveness).
