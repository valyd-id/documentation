# Face match

> 📄 **This page moved.** Face match is documented in the
> **[checks reference](/verifications/types)**. This stub stays so old links keep working.

Face match is a **workflow check** inside [Reusable Verification](/verifications): run a
configured [workflow](/verifications/workflows) on a session with the user's
`valyd_access_token`, and the selfie matches against their enrolled face vector with the result
riding on their account. (It is not a public API call.) See the
[checks reference](/verifications/types).
