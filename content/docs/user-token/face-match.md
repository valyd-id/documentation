# Face match

> 📄 **This page moved.** Face match is documented in one canonical place:
> **[Face match](/verifications/standalone/face-match)**. This stub stays so old links keep working.

Running face match for a signed-in user is the **same call** as the one-off check — you just add
the user's `valyd_access_token`, so the selfie matches against their enrolled face vector and the
result rides on their account. See [Face match](/verifications/standalone/face-match).
