# Face match

> 📄 **This page moved.** Face match is documented in one canonical place:
> **[Face match](/verifications/standalone/face-match)**. This stub stays so old links keep working.

Running face match for a signed-in user is a **[Managed by Valyd](/verifications/managed)** check —
you run it on a hosted session with the user's `valyd_access_token`, so the selfie matches against
their enrolled face vector and the result rides on their account. (Face match is not a self-serve
direct call.) See [Face match](/verifications/standalone/face-match).
