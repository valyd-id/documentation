# Verify for your users

> 📄 **This page moved.** Running verifications on Valyd's verification page is documented in one
> canonical place: **[Run a verification](/verifications/quickstart)**. This stub stays so old
> links keep working.

Running a workflow for a connected user is the **same integration** as any verification session —
you just include the user's `valyd_access_token` when creating it, so passed proofs save to their
Valyd ID and already-proven steps are skipped.

- Full guide: [Run a verification](/verifications/quickstart)
- Saving proofs to the account: [Reusable Verification](/verifications)
- Read proofs back on the next login: [Read verified data](/docs/user-token/account)
