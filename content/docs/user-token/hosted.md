# Hosted for your users

> 📄 **This page moved.** Hosted verification is now documented in one canonical place:
> **[Hosted verification](/verifications/hosted)**. This stub stays so old links keep working.

Hosting the whole flow for a signed-in user is the **same integration** as any hosted session —
you just include the user's `valyd_access_token` when creating it, so passed proofs save to their
Valyd ID and already-proven steps are skipped.

- Full guide: [Hosted verification](/verifications/hosted)
- Saving proofs to the account: [Verify & save a proof](/verifications/managed)
- Read proofs back on the next login: [Read proofs](/docs/user-token/account)
