# Verify a professional license

Professional-license verification is no longer a self-serve direct API call. It now runs through
**[Managed by Valyd](/verifications/managed)** — the licensed professional signs in with Valyd, you
run a hosted verification session with their `valyd_access_token`, and the verified license badge
saves to their Valyd ID (reusable, no re-check next time). The name is taken from their verified
account, so a holder can't be checked against someone else's license.

- **How to run it:** [Managed by Valyd](/verifications/managed) · [Hosted verification](/verifications/hosted)
- **Which checks & availability:** [Verification types](/verifications/types)
- The `POST /api/v2/credential-verification` endpoint still exists in the
  [Verification OpenAPI](/verifications/api) for existing integrations.
