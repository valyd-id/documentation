# Reusable Verification (moved)

> 📄 **This page moved.** The Reusable Verification overview now lives at
> **[/verifications](/verifications)**. This stub stays so old links keep working.

Connect the user with Valyd (OIDC), read the verified data they consent to share, and run your
configured [workflow](/verifications/workflows) for anything missing — the session is created
through the SDK with the user's `valyd_access_token`, and passed proofs save to their Valyd ID.
