# Location

This check now runs through **Managed by Valyd** — [Verify & save a proof](/verifications/managed).

Location is no longer a self-serve direct call. Run it on a signed-in user's hosted verification
session (for example in an EVV workflow); your app receives the location decision as part of the
session result.

The `POST /api/v2/location` endpoint still exists in the
[Verification OpenAPI](/verifications/api) for existing integrations.
