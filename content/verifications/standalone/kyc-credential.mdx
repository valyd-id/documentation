# KYC + Credential

This check now runs through **Managed by Valyd** — [Verify & save a proof](/verifications/managed).

The combined KYC + license check is no longer a self-serve direct call. Run it on a signed-in
user's hosted verification session: ID, liveness, face match, and the license lookup complete
together, the raw identity data stays encrypted with Valyd, and your app receives the decision plus
reusable proofs.

The `POST /api/v2/kyc-credential` endpoint still exists in the
[Verification OpenAPI](/verifications/api) for existing integrations.
