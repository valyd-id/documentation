# Credential Verification

This check now runs through **Managed by Valyd** — [Verify & save a proof](/verifications/managed).

Professional-license verification is no longer a self-serve direct call. Run it on a signed-in
user's hosted verification session: the license is matched against the account's verified name and
the passed badge is saved to their Valyd ID as a reusable proof.

The `POST /api/v2/credential-verification` endpoint (and the state / provider discovery endpoints)
still exists in the [Verification OpenAPI](/verifications/api) for existing integrations.
