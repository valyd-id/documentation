# Full OpenAPI spec — Verification API

The complete, machine-readable OpenAPI 3.1 specification for the Verification API — hosted
sessions, core standalone checks, credentials, workflows, and the HMAC-SHA256 webhook schema.

- **Download / fetch:** [`/openapi/valyd-verify.json`](/openapi/valyd-verify.json)

```bash
curl -sL https://docs.valyd.work/openapi/valyd-verify.json
```

For the human-readable endpoint list — every call, request format, and the standard response
envelope — see the [API reference](/verifications/api-reference) page. Webhook signature
verification is covered in [Webhooks](/verifications/webhooks).
